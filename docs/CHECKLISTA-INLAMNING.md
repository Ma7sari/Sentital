# Checklista innan inlämning

Kör igenom innan någon lämnar GitHub-länken i Itslearning.

Vi har **inte** Trello/Figma/Drive-länkar i README på riktiga dokument – vi har skrivit varför i **VAR-LIGGER-VAD**. Om kursen kräver det ändå, fråga läraren eller lägg upp en kort logg i Drive i efterhand och länka.

Kolla att repot är publikt eller att **tbprogrammering** är inbjuden om det är privat. Rätt branch (hos oss **master**). Fler commits under tiden ser bättre ut än en enda jättecommit sista dagen.

README ska ha **vem** som gjort **vad**, kort **vad appen är**, och **var** mer finns (**docs/**). Teknisk beskrivning, testrapport, agilt, användarmanual finns i docs.

Koden: `npm install` och `npm start` i **server** med `.env` enligt README. Inga nycklar i Git.

Inför redovisning: något som **funkar**, och säg öppet om något **inte** hanns med.

Lycka till.
